LUXE RADAR V3.3.0 — SHOPPING-FIRST UI

Objectif
- rendre l'application compréhensible dès la première visite ;
- rendre tous les onglets principaux visibles ;
- rapprocher l'expérience d'un comparateur de prix grand public sans copier une marque ;
- conserver le moteur de pertinence V3.2.0 et ses protections anti-bruit.

Interface
- navigation horizontale persistante : Accueil, Comparer les prix, Favoris, Alertes prix, Historique, Outils, Catalogue, Premium ;
- recherche globale toujours visible sur ordinateur ;
- accueil centré sur une grande recherche, les recherches populaires et des catégories ;
- raccourcis vers comparaison, alertes, favoris et historique ;
- recherches récentes visibles sur l'accueil ;
- mode clair par défaut, thème sombre retravaillé, 9 accents conservés ;
- résultats simplifiés, filtres secondaires repliés ;
- mobile simplifié avec navigation horizontale accessible.

Fonctionnalités conservées
- pertinence précise V3.2.0 ;
- mode exact / tout voir ;
- prix minimum / médian / moyen ;
- favoris ; alertes prix ; historique ; comparateur ; recherche par image ; export ;
- scroll infini avec anti-spam ;
- fast-fail des sources bloquées ;
- aucun contournement CAPTCHA / 403.
